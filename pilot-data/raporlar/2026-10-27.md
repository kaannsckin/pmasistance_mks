# Pilot raporu — 2026-10-27 (Salı)

**Demo kararı:** Hazır değil — pilot ortamı bulut verisine ulaşamıyor; ajanlar başlatılmadı.
**Kod birleştirme:** Hazır değil — son 3 koşuda kontrol ölçütü sağlanamadı (bu koşuda kontrol 0/1, ortam erişimi yok).

## Özet
- Otomatik kontroller: 0/1 geçti ([kontrol.md](../gunluk/2026-10-27/kontrol.md)) · demo yolu testi: koşmadı
- Kullanıcılar: ajan başlatılmadı (talimat: bulut verisine ulaşılamıyorsa ajanları başlatma). Puan önerisi yok; `puanlar.json` değişmedi.
- Bulgular: değişmedi (`bulgular.json`'a dokunulmadı; aşağıdaki durumlar uygulama bulgusu değil, ortam engelidir).

## Engeller (komut çıktısıyla)
1. `npm run -s pilot -- kontrol` → `Çalışma alanı okunamadı: TypeError: fetch failed`
2. `curl https://yzwmllzfynsrtlgxrpnw.supabase.co/rest/v1/` → `curl: (56) CONNECT tunnel failed, response 502` (ajan proxy'si bu ortamda Supabase sunucusuna tünel açmıyor; `PILOT_SUPABASE_*` değişkenleri tanımlı, 5 adet).
3. `npm run -s pilot -- ozet` → `durum.json sürümü 3, beklenen 4: simülasyon değişti. Pilotu baştan kurun: baslat --zorla`. Kod dalındaki simülasyon sürümü yükselmiş; yerel `pilot-data/durum.json` eski. `baslat --zorla` pilot verisini sıfırlayacağından talimatta yetki olmadan çalıştırılmadı; 1. rutin / kullanıcı karar vermeli.
